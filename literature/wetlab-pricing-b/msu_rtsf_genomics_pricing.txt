 Pricing

 Pricing effective July 1, 2026. 

 Pricing is identical for MSU researchers and for off-campus researchers. However,
 payments from non-MSU accounts (i.e. off-campus researchers) will be subject to a
 3% University Administrative Fee. MSU also requires the addition of a 26% Facilities
 and Administrative Cost charge to services provided to for-profit companies.

 and/or size of nucleic acids. It performs the same function as a bioanalyzer, but
 allows for high-throughput sample processing.

 10X Genomics Chromium Single Cell Library Preparation Services 

 The Genomics Core has a Chromium X instrument. We offer 10X single cell and single
 nuclei library preparation services. 10X library preparation options include: Flex
 v2/APEX Gene Expression GEM-X, Universal 3' Gene Expression v4 GEM-X (Multiplex and
 Standard), Universal 5' Gene Expression v3 GEM-X (Multiplex and Standard), Epi ATAC,
 and Epi Multiome ATAC. Contact the Genomics Core at gtsf@msu.edu to discuss project

 Library/pool Size-Selection

 Pippin Prep Size-Selection

 The Sage Pippin Prep can be used for size selection of completed libraries or pools. 
 The Genomics Core only offers one cassette, which allows for size selection in the
 range of 100 - 600 bp. This size selection method is not offered for individual samples. It is used by the Genomics Core to reduce the presence of primer dimers and/or other
 off-target products in completed libraries. Researchers should contact the Genomics
 Core (gtsf@msu.edu) before submission of user-prepared libraries or pool(s) if they
 feel that size selection is needed.

 Zymo Select-a-Size

 Select-a-Size (Zymo part number D4080) can be used to select for fragments ≥ 300 bp
 or ≥ 200 bp. This size selection method is not offered for individual samples . It is used by the Genomics Core to reduce the presence of barcoded primer dimers
 in amplicon libraries. Researchers should contact the Genomics Core (gtsf@msu.edu) before submission of user-prepared
 libraries or pool(s) if they feel that size selection is needed.

 Magnetic Bead Cleanup 
 
 A magnetic bead cleanup can be used to remove small contaminating fragements (i.e.
