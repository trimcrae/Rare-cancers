Genomics of Drug Sensitivity in Cancer 

 Site Update

 The Genomics of Drug Sensitivity in Cancer datasets and features have now been integrated into the Sanger DepMap where users can explore them using enhanced functionality and improved analytical tools.

 Please use the information and links below to access and explore the data via the Cell Model Passports and DepMap Miner.

 How to access the Genomics of Drug Sensitivity in Cancer data:

 Download the GDSC1 & GDSC2 datasets from the Cell Model Passports .

 Explore the data using the DepMap Miner .

 Learn more about the dataset from the Sanger DepMap documentation .

 Features available in the Sanger DepMap:

 Example visualisations and features available across the Sanger Depmap to explore the GDSC drug sensitivity data.

 Single Drug, ranked analysis from the DepMap Miner

 Compare drug response across cell models using the DepMap Miner’s Single Drug Analysis.
 Customise the plot and export the associated data.

 Single Drug, categorical analysis from the DepMap Miner

 Observe the variation in response relative to the model’s tissue, cancer type and other characteristics.

 Drug Sensitivity, single model from the Cell Model Passports

 Discover the relative sensitivities of a specific model within the GDSC2 dataset using the Cell Model Passports Drug Sensitivity Panel.

 Sort and filter the list to display specific compounds or drug targets.
