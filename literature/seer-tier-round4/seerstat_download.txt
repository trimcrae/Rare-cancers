 SEER*Stat is a Microsoft Windows application. The software can only be used on a Mac if it's run within a Windows emulator.

 A few important points: 

 Registering for the SEER*Stat Software is different than requesting the SEER data.
 
 If you already have access to the SEER data but have not installed SEER*Stat, complete the software registration form below.

 If you do not yet have access to the SEER data, refer to instructions how to request the data .

 After you have downloaded and installed SEER*Stat for the first time, the software can be configured to automatically update with each SEER*Stat release.

 To get advance notice of SEER*Stat software releases, refer to Updates for SEER*Stat and SEER Data . 

 Before downloading SEER*Stat version 9.0.43 , you must read and sign the Terms of Use Agreement below and complete the registration form. After completing the form you will receive an e-mail with a link to the software download. The download link will expire after 24 hours. If your link has expired, request a new one using the Already Registered? form .
