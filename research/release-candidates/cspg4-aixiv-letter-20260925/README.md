# CSPG4 Letter preprint update

This public package contains the concise CSPG4 Letter with Figure 1 followed by its complete Supplementary Information: 4 main pages and 17 supplementary pages. It matches the scientific text submitted to Cancer Genetics as a Letter, with public author information, declarations and data/code link restored. Journal submission does not imply acceptance.

The main and supplementary pages are preserved from the accepted September 24 author-review PDFs. The title and retained abstract metadata are unchanged. Earlier aiXiv versions remain historical.

The accompanying data and code archive is linked inside the paper. No private journal forms or postal address are included.
