# PARKED (do not action) — methods-spinout idea

**Status: PARKED 2026-07-12 by trimcrae ("file it away and forget"). Not a workstream. Do NOT spend effort on
this; it exists only so the idea isn't lost.**

Idea: a possible standalone methods paper — *"Error-controlled, budget-constrained multi-fidelity allocation
for computational degrader (PROTAC) selectivity screening."* The one genuinely novel piece is the
**certification/decision layer** (thresholded good-arm identification with campaign-wide anytime-valid
false-declaration control + noncompensatory multi-paralogue selectivity), which composes *on top of* existing
allocation methods (successive-halving/Hyperband, active-learning FEP, multi-fidelity BO) rather than
replacing them. Not a new optimizer.

Only revisit if (a) the NR4A3 program's own retrospective validation happens to produce a clean, publishable
benchmark for free, and (b) trimcrae explicitly re-opens it. Otherwise: forgotten on purpose.
