# Cover letter draft

Dear Editors,

Please consider “Training support and score weighting alter conclusions in a public sarcoma methylation reanalysis” as an Original Article in Virchows Archiv, using the subscription publication route.

This empirical methods reanalysis examines how evaluation choices affect confidence in sarcoma methylation assignments. Using released measurements and a separate fixed model, matching class-specific training support substantially attenuated a supplier-versus-sample Brier-score gap. Reference-fitted score sharpening increased high-threshold assignments but did not consistently improve log loss across class weighting and zero-vote conventions. A recorded discordant profile became an above-threshold assignment.

The contribution is a bounded, reproducible demonstration in one public dataset, relevant to the interpretation of diagnostic scores. It is not a new biological subtype, a validation of current clinical software, or an estimate of EMC diagnostic sensitivity. We retain the selected annotation reference standard, fixed-subsampling limitation, epsilon sensitivity, incomplete patient linkage, and unresolved external-source denominator discrepancy. No external-cohort prediction analysis is claimed.

The package includes an editable manuscript, two source-linked main tables, a methods supplement, and a compact archive of frozen predictions, training ledgers, input hashes and executable table/reaggregation code. Funding and competing-interest declarations state none, as previously confirmed by the author. AI assistance is described in Methods.

Sincerely,

Tristan D. McRae
