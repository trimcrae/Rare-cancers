Reproducibility guide
Online Resource 1 for “A row-ordinal sample-ID transformation in a public sarcoma rearrangement export”
Human Genetics correspondence preparation. Tristan D. McRae, independent researcher, unaffiliated. Correspondence: trimcrae@gmail.com.
Scope and evidence
This package documents source identifiers in one pinned derivative export. It supplies the original archived inputs, mapping and corrected export, together with the recovery program and the already completed independent check. No primary extraction or scientific analysis was rerun for this preparation.
The reconstruction aligns events in retained workbook/export order. Repeated gene pairs do not independently establish unique event identity. The correction changes Sample_Id only and retains all other export fields, including unresolved annotations and all 564 literal N/A tokens. It is a proposed derivative for curator reconciliation, not evidence of a corrected portal, biological function or clinical effect.
Archived inputs
Use primary-inputs.zip at repository revision 5d2f2e2116f43c0bb56a46120902a1332f27720b. The archive SHA-256 is e37eecc77a001f3265db074bb9f5a86ec3736752c855664d992bf00fc200db3b. Its four members are primary.xls (published workbook), data_sv.txt (pinned export), mapping.json (complete source mapping), and data_sv.identity_corrected.tsv (proposed identity-only correction).
The machine-readable source-archive.json contains every member's exact byte count and SHA-256. Both the outer ZIP and all four members were hash-verified during preparation. The original ZIP was preserved unchanged.
Reproduction
The companion reproducibility.zip supplies the unmodified input archive, recovery code, independent-check code, saved primary-confirmation output, gene-annotation summary and licence notices. Unpack it into a new directory. Run verify_package.py to verify the manifest and archived member hashes using Python 3.9 or later; this check does not redo the science.
The optional offline reproduction commands in README.txt restore the source IDs from the archived mapping and compare the output hash. Repeating the independent primary-workbook extraction uses xlrd 2.0.1, the version recorded in the historical run, and only the archived workbook. Neither command requests a live portal or a new primary download. These commands are for readers; the validated extraction from run 37035103326 is reused here.
Existing result and annotation records
The independent check confirmed 3,771 source mappings and 3,771 corrected identifiers, 3,770 original-ID disagreements, 7,494 clinical profiles and 3,182 distinct source identifiers among rearrangement events. The source EMC group has 75 profiles and 76 events; selecting with its original identifiers in the faulty export returns 28 events from other source records and zero source EMC events.
Fifteen literal gene-pair differences are retained separately. Current HGNC alias/previous-symbol evidence supports 12 events. Two date-formatted spreadsheet cells do not establish intended genes; AKAP2/PALM2AKAP2 remains a distinct-record issue. No gene annotation is silently repaired.

Interpretation limits
The independent extraction uses a separate code path but the same xlrd reader family. This is not an independent file-format-parser validation. Source labels, somatic status, functional fusions, importer compatibility and live deployment were not validated. An event count is not an independently verified patient count. The package is computational evidence for a fixed-file correction.
