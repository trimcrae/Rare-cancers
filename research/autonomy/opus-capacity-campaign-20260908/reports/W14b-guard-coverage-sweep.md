### Code — the three tools (returned inline, not written into the tree)

`tools/enumerate_generators.py`:

```python
#!/usr/bin/env python3
"""Mechanically enumerate scripts that write a COMMITTED artifact.

Method (static, reproducible):
  1. candidate scripts = top-level *.py in the four named directories
  2. a script is a GENERATOR CANDIDATE if it contains a write idiom
  3. its artifact literals are resolved against `git ls-files`
Emits TSV: script, n_write_idioms, n_committed_artifacts, artifacts
"""
import ast, pathlib, re, sys

ROOT = pathlib.Path(sys.argv[1])
tracked = [l.strip() for l in (ROOT / "TRACKED.txt").read_text().splitlines() if l.strip()]
by_base = {}
for t in tracked:
    by_base.setdefault(pathlib.PurePath(t).name, []).append(t)
tracked_set = set(tracked)

DIRS = ["research/manuscripts", "research/modalities", "scripts", "systems"]
WRITE_RE = re.compile(r"\.write_text\(|\.write_bytes\(|\.to_csv\(|savefig\(|json\.dump\("
                      r"|open\([^)]*['\"][wa]b?['\"]")
EXT = {".json", ".csv", ".tsv", ".md", ".txt", ".png", ".svg", ".html",
       ".yaml", ".yml", ".jsonl", ".fasta", ".bib", ".pdf"}

rows = []
for d in DIRS:
    for p in sorted((ROOT / d).glob("*.py")):
        src = p.read_text(encoding="utf-8", errors="replace")
        hits = WRITE_RE.findall(src)
        if not hits:
            continue
        lits = set()
        try:
            for node in ast.walk(ast.parse(src)):
                if isinstance(node, ast.Constant) and isinstance(node.value, str):
                    lits.add(node.value)
        except SyntaxError:
            lits.update(re.findall(r"['\"]([^'\"\n]{3,120})['\"]", src))
        arts = set()
        for s in lits:
            s = s.strip().lstrip("./")
            if not s or "\n" in s or " " in s.strip():
                continue
            if pathlib.PurePath(s).suffix not in EXT:
                continue
            if s in tracked_set:
                arts.add(s); continue
            for cand in by_base.get(pathlib.PurePath(s).name, []):
                if cand.endswith(s) or cand.startswith(d + "/"):
                    arts.add(cand)
        rows.append((f"{d}/{p.name}", len(hits), sorted(arts)))

print("script\tn_write_idioms\tn_committed_artifacts\tartifacts")
for s, n, a in rows:
    print(f"{s}\t{n}\t{len(a)}\t{','.join(a)}")
print(f"# TOTAL scripts with a write idiom: {len(rows)}", file=sys.stderr)
```

`tools/probe_guards.py` — the decisive empirical classifier:

```python
#!/usr/bin/env python3
"""Empirically classify every candidate generator's guard state.

For each candidate script, in an ISOLATED SCRATCH COPY of the tree:
  probe 1  bare run            -> which git-TRACKED files did it modify? (generator-hood)
  probe 2  `--check`           -> exit code, and did it modify its own artifact?
  probe 3  `--w14b-bogus-flag` -> exit code (0 == parses no arguments at all)
After every probe the tree is restored from the pristine master, so probes never
contaminate each other. NOTHING under /home/user/Rare-cancers is touched.
"""
import json, os, pathlib, shutil, subprocess, sys, time

PRISTINE = pathlib.Path("/tmp/claude-0/w14b")
SCRATCH = pathlib.Path(sys.argv[1])
SCRIPTS = [l.strip() for l in pathlib.Path(sys.argv[2]).read_text().splitlines() if l.strip()]
OUT = pathlib.Path(sys.argv[3])
TIMEOUT = int(os.environ.get("PROBE_TIMEOUT", "20"))

tracked = {t for t in (l.strip() for l in (PRISTINE / "TRACKED.txt").read_text().splitlines())
           if t and (SCRATCH / t).exists()}

def snapshot():
    return {t: (SCRATCH / t).stat().st_mtime_ns for t in tracked}

def run(script, *flags):
    before = snapshot()
    t0 = time.time()
    try:
        p = subprocess.run([sys.executable, script, *flags], cwd=str(SCRATCH),
                           capture_output=True, text=True, timeout=TIMEOUT)
        rc, out, err = p.returncode, p.stdout, p.stderr
    except subprocess.TimeoutExpired:
        rc, out, err = "TIMEOUT", "", ""
    after = snapshot()
    changed = sorted(t for t in tracked if after[t] != before[t])
    for c in changed:                       # restore, content- and mtime-preserving
        shutil.copy2(PRISTINE / c, SCRATCH / c)
    return {"rc": rc, "secs": round(time.time() - t0, 2), "wrote": changed,
            "out": (out or "")[-400:], "err": (err or "")[-400:]}

with OUT.open("w") as fh:
    for s in SCRIPTS:
        rec = {"script": s, "bare": run(s)}
        if rec["bare"]["wrote"]:
            rec["check"] = run(s, "--check")
            rec["bogus"] = run(s, "--w14b-bogus-flag")
        fh.write(json.dumps(rec) + "\n"); fh.flush()
```

## Limitations

- **This is tooling, not science.** No artifact content changed, no number moved, nothing here bears on EMC biology, efficacy, safety, selectivity or clinical readiness. I repaired nothing and touched no guard.
- **"Enforced" is a name-mention heuristic except for the preflight gate.** Gate membership is exact (parsed from the shell array). But a script's stem appearing in a workflow or test file proves only that the name is mentioned — very often the workflow *runs the generator* rather than drift-checking it. So `GUARDED-AND-ENFORCED` (63) is an **upper bound** on real enforcement, and the `GUARDED-NOT-ENFORCED` count (8) is a **lower bound**. Only the 9 verified gate rows are enforcement I have actually confirmed end to end.
- **"Cited by prose" is a filename-mention count, not a measure of whether a manuscript quotes a number derived from the artifact.** It under-ranks exactly the artifacts W14 proved were load-bearing: `emc-relative-survival.json` and `emc-terminal-events.json` score 0 here, yet the research ledger records a real corrected quantity in that family (the competing share moving 39.4 % → 21.7 %). Treat the ranking as a triage aid, not a severity metric.
- **45 candidates timed out at 20 s on the bare run and are UNDETERMINED, not clean.** Their generator-hood and guard state are UNKNOWN, not zero. They cluster in `research/modalities` (network- or compute-bound). Raising the timeout would resolve them.
- **7 of the 18 gate rows write only under an explicit `--write` and so were not classified as generators by my bare-run probe.** They are named above; their exclusion is a limit of my method, not evidence about them.
- **`GUARD-PRESENT-CURRENTLY-RED` is measured in scratch only.** Some of those 12 may be red because the scratch copy is not a git repository, has no network, or because a probe of a *different* script regenerated a shared input earlier in the same slice. At least one (`emc_hypoxia_confounds`) reports a differing `_source_inputs_generated_utc`, which is a cry-wolf-prone comparison field. **Whether any of these is red in the real tree is UNKNOWN** — I did not run them there and do not claim it.
- Probes ran under CPU contention with other concurrent campaign workers; timings are not benchmarks.
- The scratch copy excludes `.git`, so `git`-dependent checks (`git ls-files`, `origin/main`) behave differently there — the same artifact W14 documented for two `emc_systems_map_check` tests.
