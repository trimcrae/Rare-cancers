"""
W02d - four-part artifact battery on the EMC tumour-marker and fibro/ECM compartment
scores, with the immune axis run through identical machinery as a NEGATIVE CONTROL
that is EXPECTED TO FAIL (i.e. expected to show no excess variance to defend).

Input: research/modalities/emc-expression-panels.json, GPL6244 (GSE24369) ONLY.
No cross-platform pooling. Scores are means of per-gene within-array percentiles.
A compartment score is a PREDICTION about composition, never a measurement of cells.

=====================  PASS/FAIL CRITERIA - DECLARED BEFORE THE RUN  =====================
Thresholds are set PER MARKER SET from that set's OWN comparator arms, not from the
endothelial set. They are declared here as rules and computed inside the run so that no
number is tuned after seeing a result. For each marker set X in {tumour, fibroECM,
immune}, let SD_EMC(X) be the EMC between-specimen SD (ddof=1, n=6) of score X, and let
FLOOR(X) = max over comparator arms {LGFMS n=17, desmoid n=6, fibrosarcoma n=6} of that
arm's SD of the SAME score X.

(a) OUTLIER / LEAVE-ONE-SPECIMEN-OUT.
    FAIL (= outlier-driven, does NOT survive) if min over the six leave-one-out SDs of
    score X is <= FLOOR(X). PASS otherwise.

(b) SMALL-n SAMPLING ARTIFACT.
    Permutation against REAL LGFMS six-specimen resamples of the same score X: draw
    20000 resamples of 6 of the 17 LGFMS specimens without replacement, compute each
    resample's SD. FAIL (= small-n artifact) if P(resample SD >= SD_EMC(X)) > 0.05.
    PASS otherwise. Levene / F-test reported alongside as descriptive, not as criteria.

(c) MARKER COMPOSITION / LEAVE-ONE-MARKER-OUT.
    FAIL (= composition-driven) if any leave-one-marker-out SD of score X falls to
    <= FLOOR(X). PASS otherwise. Reported alongside: size-matched random-gene-panel null
    using the SET'S OWN gene count k (9 tumour, 14 fibroECM, 12 immune), 5000 draws from
    genes not in any of the four marker sets; P(random k-gene SD_EMC >= SD_EMC(X)).

(d) PER-SPECIMEN TECHNICAL EFFECT.
    FAIL (= technical) if |r| >= 0.8 (Pearson, n=6) between score X in the EMC specimens
    and any per-specimen technical covariate (panel-wide mean percentile; readable-gene
    count, if it varies). PASS otherwise.

OVERALL VERDICT per set: "survives" only if (a),(b),(c),(d) all PASS. Any FAIL => "does
not survive", named by route. The immune axis is run identically and is EXPECTED to fail
(b) because its EMC/LGFMS ratio is 1.00x; if it instead passed everything, the battery
would be suspect.

Absolute SDs are NOT comparable across marker sets of different gene counts (averaging
14 genes damps between-specimen variance more than averaging 9). Absolute SDs and
within-set EMC/LGFMS ratios are therefore reported SEPARATELY.
=========================================================================================
"""
import json, collections
import numpy as np
from scipy import stats

SRC = "/home/user/Rare-cancers/research/modalities/emc-expression-panels.json"
PLAT = "GSE24369_series_matrix.txt.gz"   # GPL6244
ENDO = ["PECAM1","VWF","CDH5","KDR","FLT1","MCAM"]
IMM  = ["PTPRC","CD2","CD3D","CD3E","CD8A","CD68","CD163","CSF1R","ITGAM","HLA-DRA","MS4A1","GZMB"]
FIB  = ["COL1A1","COL1A2","COL3A1","COL5A1","DCN","LUM","FAP","THY1","POSTN","FN1",
        "PDGFRA","PDGFRB","ACTA2","COL11A1"]
TUM  = ["NR4A3","PPARG","RET","INSM1","SYP","CHGA","ENO2","KIT","CD24"]
SETS = [("tumour", TUM), ("fibroECM", FIB), ("immune", IMM)]
RNG = np.random.default_rng(20260908)

d = json.load(open(SRC))
print("input generated_utc:", d.get("generated_utc"))
gr = d["gene_reads"]
genes, classes = {}, {}
for g, v in gr.items():
    pv = v.get(PLAT)
    if not pv or not pv.get("readable"): continue
    row = {}
    for s in (pv.get("per_sample") or []):
        classes[s["gsm"]] = s["class"]
        if s.get("array_percentile") is not None: row[s["gsm"]] = s["array_percentile"]
    if row: genes[g] = row
S = sorted(classes)
names = [g for g in genes if all(x in genes[g] for x in S)]
M = {g: np.array([genes[g][x] for x in S]) for g in names}
print("GPL6244 readable=%d complete-case=%d samples=%d %s" %
      (len(genes), len(names), len(S), dict(collections.Counter(classes.values()))))
CLS = sorted(set(classes.values()))
IDX = {c: [i for i, s in enumerate(S) if classes[s] == c] for c in CLS}
emc_idx = IDX["EMC"]; emc_gsm = [S[i] for i in emc_idx]
CMP = [c for c in CLS if c != "EMC"]

def score(markers):
    ok = [g for g in markers if g in M]
    return np.mean([M[g] for g in ok], axis=0), ok

panelmean = np.array([np.mean([M[g][i] for g in names]) for i in range(len(S))])
readable  = np.array([sum(1 for g in genes if S[i] in genes[g]) for i in range(len(S))])
pool = [g for g in names if g not in set(ENDO+IMM+FIB+TUM)]
print("eligible random-panel gene pool = %d genes" % len(pool))
print("readable-gene count distinct values across 35 samples:", sorted(set(readable.tolist())))

print("\n### Reference table: absolute SDs and within-set EMC/LGFMS ratios (NOT comparable across sets)")
print("%-10s %2s | %-8s %-8s %-8s %-8s | ratio  Ftest_p" % ("set","k","EMC","LGFMS","desmoid","fibrosarc"))
store = {}
for nm, mk in [("endothelium", ENDO)] + SETS:
    v, ok = score(mk)
    sds = {c: v[IDX[c]].std(ddof=1) for c in CLS}
    F = sds["EMC"]**2 / sds["LGFMS"]**2
    p = 2*min(stats.f.sf(F,5,16), stats.f.cdf(F,5,16))
    print("%-10s %2d | %-8.4f %-8.4f %-8.4f %-8.4f | %.2fx  %.4f" %
          (nm, len(ok), sds["EMC"], sds["LGFMS"], sds["desmoid_fibromatosis"], sds["fibrosarcoma"],
           sds["EMC"]/sds["LGFMS"], p))
    store[nm] = (v, ok, sds)

for nm, mk in SETS:
    v, ok, sds = store[nm]
    x = v[emc_idx]; SD = x.std(ddof=1)
    FLOOR = max(sds[c] for c in CMP)
    tag = "NEGATIVE CONTROL, EXPECTED TO FAIL" if nm == "immune" else "test set"
    print("\n" + "="*78)
    print("MARKER SET: %s  (k=%d markers used: %s)  [%s]" % (nm, len(ok), ",".join(ok), tag))
    print("  EMC per-specimen score: %s" % dict(zip(emc_gsm, np.round(x,4).tolist())))
    print("  SD_EMC = %.4f ; FLOOR (largest comparator SD, this set) = %.4f (%s)" %
          (SD, FLOOR, max(CMP, key=lambda c: sds[c])))
    res = {}

    loo = [(emc_gsm[i], np.delete(x,i).std(ddof=1)) for i in range(6)]
    lo = min(s for _,s in loo)
    res['a'] = lo > FLOOR
    print("\n (a) leave-one-specimen-out: %s" % " ".join("%s=%.4f"%(g,s) for g,s in loo))
    print("     min LOO SD = %.4f vs FLOOR %.4f -> %s" % (lo, FLOOR, "PASS" if res['a'] else "FAIL (outlier-driven)"))

    lg = v[IDX["LGFMS"]]
    draws = np.array([np.random.default_rng(1000+t).choice(lg,6,replace=False).std(ddof=1) for t in range(20000)])
    pperm = (draws >= SD).mean()
    res['b'] = pperm <= 0.05
    print("\n (b) LGFMS six-specimen resamples (20000): mean=%.4f p95=%.4f max=%.4f ; P(>=SD_EMC)=%.5f -> %s"
          % (draws.mean(), np.percentile(draws,95), draws.max(), pperm, "PASS" if res['b'] else "FAIL (small-n artifact)"))
    allc = np.concatenate([v[IDX[c]] for c in CMP])
    print("     descriptive: Levene(median) EMC vs pooled comparators W=%.3f p=%.5f" % stats.levene(x, allc, center='median'))

    lom = []
    for g in ok:
        vv,_ = score([q for q in ok if q != g]); lom.append((g, vv[emc_idx].std(ddof=1)))
    lomin = min(s for _,s in lom); lomax = max(s for _,s in lom)
    res['c'] = lomin > FLOOR
    print("\n (c) leave-one-marker-out SD range = [%.4f, %.4f] vs FLOOR %.4f -> %s"
          % (lomin, lomax, FLOOR, "PASS" if res['c'] else "FAIL (composition-driven)"))
    print("     driver/diluter: %s" % " ".join("%s=%.4f"%(g,s) for g,s in sorted(lom, key=lambda t:t[1])))
    k = len(ok)
    rnd = np.empty(5000)
    for t in range(5000):
        pick = RNG.choice(len(pool), k, replace=False)
        rnd[t] = np.mean([M[pool[i]] for i in pick], axis=0)[emc_idx].std(ddof=1)
    print("     size-matched random %d-gene panels: mean=%.4f p95=%.4f ; P(random SD_EMC >= SD_EMC(%s)) = %.4f"
          % (k, rnd.mean(), np.percentile(rnd,95), nm, (rnd>=SD).mean()))

    r1 = stats.pearsonr(x, panelmean[emc_idx])
    print("\n (d) EMC score vs panel-wide mean percentile: r=%.3f p=%.3f" % (r1[0], r1[1]))
    rs = [abs(r1[0])]
    if len(set(readable[emc_idx].tolist())) > 1:
        r2 = stats.pearsonr(x, readable[emc_idx].astype(float)); rs.append(abs(r2[0]))
        print("     EMC score vs readable-gene count: r=%.3f p=%.3f" % r2)
    else:
        print("     EMC score vs readable-gene count: UNDEFINED - coverage identical in every EMC sample")
    res['d'] = max(rs) < 0.8
    print("     max |r| = %.3f vs 0.80 -> %s" % (max(rs), "PASS" if res['d'] else "FAIL (technical)"))

    ok_all = all(res.values())
    print("\n VERDICT[%s]: %s   (a=%s b=%s c=%s d=%s)" % (
        nm, "SURVIVES all four artifact routes" if ok_all else
        "DOES NOT SURVIVE - fails: " + ",".join(kk for kk,vv2 in res.items() if not vv2),
        *["PASS" if res[q] else "FAIL" for q in "abcd"]))
print("\n" + "="*78)
print("Reminder: absolute SDs are NOT comparable across marker sets of different gene counts.")

## Limitations

1. **n = 6 EMC specimens on one array (GPL6244 / GSE24369).** Every SD here is estimated from six numbers. The battery bounds *artifact* explanations; it does not make six specimens into a cohort. **Arrays or specimens do not imply new patients.**
2. **Scores are PREDICTIONS about transcript composition.** A fibro/ECM score is not a measurement of collagen, matrix density, or fibroblast content; a tumour-marker score is not a measurement of tumour cell fraction; an immune score is not a measurement of infiltrate. No histology, no wet lab, no orthogonal deconvolution was available or attempted.
3. **The tumour-set failure is narrow and threshold-sensitive** (min LOO 0.0308 vs floor 0.0328). Had the floor been set from LGFMS (0.0239) instead of the largest comparator (fibrosarcoma, 0.0328), route (a) would have passed. I declared "largest comparator arm" before the run, following W02c's criterion shape, and I am reporting the outcome that rule produced rather than the one a different rule would have produced. **The honest statement is that the tumour axis is undecided-to-negative on the outlier route, not decisively refuted.**
4. **Routes (a) and (c) are vacuous whenever SD_EMC ≤ FLOOR**, which is the immune case. The control's three failures are really one informative failure — (b) — plus two by-construction ones. Anyone reusing this battery should read them that way.
5. **Only three comparator arms exist, two of them at n = 6.** The floor for the tumour and immune sets was set by a six-specimen fibrosarcoma arm, whose own SD is poorly estimated. W02c separately flagged that the fibrosarcoma endothelial score correlates with panel brightness at r = +0.845 — a caution about that arm generally.
6. **`array_percentile` is within-array normalised by construction**, which is why route (d) has little to bite on (readable-gene count is identical, 464, in all 35 samples). Route (d) is therefore the weakest of the four here — it can only detect a brightness-shaped effect that this normalisation was designed to remove. Its passes should not be over-read.
7. **Multiplicity:** three marker sets were tested. No family-wise correction was applied to the battery verdicts, because the pre-declared criteria are thresholds rather than a p-value family. The one criterion that is a p-value, route (b), returns 0.00000 and 0.00000 for the two test sets and 0.459 for the control — none is near a boundary where correction would change the verdict.
8. **Transfer limits:** I inherited W02c's marker-set definitions verbatim. If those sets are miscurated (e.g. a marker assigned to the wrong compartment), that error propagates here identically. I did not re-adjudicate marker assignment. W02c flagged `MCAM` as ambiguous in the endothelial set; I did not audit the other three sets for analogous cases.
9. This cannot claim anything about EMC vasculature, stroma, matrix deposition, immune evasion, treatment response, prognosis, or any patient. It cannot claim the fibro/ECM heterogeneity is biological rather than a fourth, untested artifact route.
