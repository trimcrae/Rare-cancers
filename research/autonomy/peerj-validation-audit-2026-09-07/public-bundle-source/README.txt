# Public sources for checking external-cohort descriptions

This bundle preserves two complete original GEO SOFT archives, the original PeerJ article XML and its original Figure S6. A standard-library Python verifier checks source hashes and independently reconciles complete deposited sample rosters and diagnostic labels. It does not compute expression values, infer patient identities, or determine which samples were analyzed in the PeerJ article.

Run offline with Python 3.9 or later, from this directory:

```text
python -X utf8 -B verify_metadata.py --output results
```

The source archives include expression and platform tables as originally deposited. The verifier explicitly skips every table body and evaluates only descriptive metadata. The resulting JSON files include all GSM accessions, raw diagnostic labels, titles, platform identifiers and original SOFT line numbers. They also record the actual command, Python version, elapsed time and pass status. Re-running replaces only the selected output directory's result files; original sources remain unchanged. `manifest.json` is a packaging inventory and is not regenerated by the verifier.

The expected deposited counts are:

- **GSE6481:** 105 samples across ten diagnosis categories; none labeled EMC or chondrosarcoma.
- **GSE24369:** 42 arrays: six EMC, 17 low-grade fibromyxoid sarcoma, six myxofibrosarcoma, six desmoid fibromatosis, five solitary fibrous tumor and two skeletal-muscle pooled-RNA controls. Array records are not a count of independently verified unique patients.

The verifier derives labels from sample characteristics and cross-checks a separate direct scan using source names (GSE6481) or titles (GSE24369). It checks exact agreement with each series' listed sample roster, uniqueness, complete inclusion, platform membership and frozen diagnosis counts. It additionally checks GSE6481's aggregate design counts and GSE24369's title numbering and tumor-biopsy versus pooled-RNA labels. A missing, inconsistent or altered record causes failure.

## Original public sources

| File in `sources/` | Original source |

| `peerj-21497-figure-s6.png` | [Original Figure S6 supplement](https://doi.org/10.7717/peerj.21497/supp-8); member `peerj-14-21497-s008.png` of the [Europe PMC supplementary archive](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13374579/supplementaryFiles) |

`source-manifest.json` gives exact URLs, original retrieval receipts, byte counts and SHA256 hashes. Copies are byte-identical to the retained original downloads. The Figure S6 receipt identifies both its original containing archive and its unchanged image hash. No figure was regenerated or digitized.

## Attribution and limits

See [ATTRIBUTION.md](ATTRIBUTION.md) for the complete PeerJ attribution and its CC BY 4.0 license. Original source terms and attribution remain attached to the sources. The Nature publisher HTML is not redistributed here.

The original Figure S6B labels its accession GSE6481 and its total as 147, while the plotted group labels state 59 other chondrosarcomas and 19 EMC. The complete official GSE6481 metadata describe a different cohort. These are source-document observations. An incorrect accession remains possible; this bundle does not identify the authors' actual analysis inputs or imply that one diagnosis was relabeled as another.
