The primary study by Bode-Lesniewska and colleagues reports FUS::DDIT3 junctions
at FUS exon 5, 7 or 8 joined to DDIT3 exon 2, designated types II, I and III,
respectively. The [primary abstract](https://pubmed.ncbi.nlm.nih.gov/17647282/)
is sufficient for these reported exon labels. Exact short excerpts, retrieval details
and limitations are in [the evidence record](primary-junctions.json).

This resolves the missing literature-label input in ledger route
`AUT-PD-208-11f2347b-8e081d15`; it does not complete the comparator analysis.
The next bounded question is conditional: with the reported exon ranks mapped to
committed FUS transcript ENST00000254108, how many native FUS RG dipeptides lie
wholly within complete codons retained through each breakpoint? Report the partial
junction codon separately and do not reconstruct it or the DDIT3 sequence.

A zero native-prefix count cannot establish a zero count for the full fusion. A
nonzero native-prefix count can challenge an all-native-RG-lost rule under the stated
mapping assumption. Do not identify these variants as the experimentally measured
FET/ATM constructs without a separate construct-to-study provenance link. The
existing census, manuscript, acceptance rule and frozen ASO release stay outside this
question. No therapeutic efficacy, safety or clinical response follows from it.
