# The NAT revision checklist, and what was done with each item

> ⛔ **The checklist is reproduced as received.** Where an item's premise turned out to be wrong,
> the finding is recorded in the disposition column rather than by editing the item — a checklist
> quietly corrected to match what was done stops being evidence of anything. Section D is the
> reviewer's own withdrawal of two earlier items and is kept for the same reason.

## A · NAT format compliance

| # | asked for | disposition |
|---|---|---|
| A1 | Restructure to IMRaD, each section beginning on a separate page | DONE. `## Introduction / Materials and Methods / Results / Discussion / Acknowledgments / Author Disclosure Statement / Statements and Declarations / References / Tables / Figure legends`; the per-section page break is `h2 { break-before: page }` in `NAT_SUBMISSION_CSS`, which is a per-paper opt-in so it cannot reach the deposited extended report. |
| A2 | Abstract to ~200 words, no citations | DONE. 200 words, measured by `submission_metrics.py`, bounded by `test_aso_abstract_is_bounded`. |
| A3 | Running title, ~45 characters | DONE. "NR4A3 junction gapmers for EMC" — 30 characters. |
| A4 | Bracketed numerals, all authors to 11 else first 9 + et al, MEDLINE abbreviations, `AAstolfi` → `A Astolfi` | DONE, with one finding: **`AAstolfi` does not exist** — not in the working tree, in any built PDF, or in any of the 70,524 blobs on `origin/literature-cache`. The author lists are generated by `journal_reference_authors.py` from fetched PubMed records, never typed; that pass found Labelle 1995 carries 13 authors rather than the 10 the pre-1996 MEDLINE cap displays, which moves it over the 11-author threshold. |
| A5 | "Author Disclosure Statement" verbatim after Acknowledgments, with "No competing financial interests exist." | DONE. |
| A6 | Double-spaced throughout, ample margins | DONE, and MEASURED rather than asserted: the Word files are opened after conversion and their line spacing read out of `document.xml` (`w:line="480"`, double at any type size). |
| A7 | Upload individual files; do NOT upload one composed PDF | DONE. `build_submission_parts.py` cuts a title page and a figure-legends file out of the manuscript, and `SUBMISSION-PACKET.md` now carries an upload manifest naming every file the portal receives. |
| A8 | Figures TIFF or EPS, line art 1200 dpi, CMYK, no Word/PowerPoint/JPEG | DONE. `figures/svg_to_print_formats.py` writes both; the manifest records the sha256 of the figure PDF each was built from so `--check` can refuse a stale deliverable. ⚠ The captured guidelines state 300 dpi; 1200 is above that and is the line-art figure this item asks for. |
| A9 | Figure legends in a separate double-spaced file | DONE, by the same builder as A7, and the legends are CUT from the manuscript rather than retyped. |
| A10 | Figure 1 must read in greyscale | DONE. Donor `#1565c0` and acceptor `#2e7d32` were 2.1% apart in BT.601 luma; they now differ by solid/dashed labelled rules and filled/open markers, so the encoding survives the conversion. The same sweep found the gap-length figure's count labels set in white on a light blend, worst case **1.87 : 1** against WCAG's 4.5, and they are now black. The three measured ratios, and the alternative that was tested and refused, are in the comment at the label in `figures/aso_gap_length_figure.py`. |
| A11 | ORCID at submission | Present in the front matter, and now also on the title page — which is what carries it when the blinded copy is the one uploaded. |
| A12 | Budget page charges (~$90/page) | DONE as a hard gate: `test_the_journal_pdf_fits_its_page_budget`. Held at 6 pages through every item below. |
| A13 | Verify the portal — material appears on both Liebert and Sage domains | ANSWERED by the guidelines trimcrae read at the primary source on 2026-08-23: Sage Track. The Publishing Services Fee survived the transfer unchanged. ⚠ `journals.sagepub.com` returns HTTP 403 to the egress proxy, to a plain CI fetch and to a real headless Chromium alike, so this row cannot be refreshed by any tool here. |
| A14 | Fix production faults: duplicated Table 1 caption; body text colliding with the table | BOTH DONE. The caption echo came from `table_label()` printing the title beside the caption on a table that does not span pages, and is removed. The collision is GONE from the rebuilt article, measured three ways: zero occurrences of either quoted string, zero lowercase→uppercase fusions anywhere in the document, and **zero overlapping text lines** across all four built PDFs. Nothing had been guarding that, so `test_no_two_lines_of_the_pdf_are_printed_on_top_of_each_other` now measures it as geometry; its threshold, the calibration behind it and the line count are in its own docstring, and it was mutation-tested against a constructed overlap, which it reports as A14's own two strings. |

⛔ **B3 IS CLOSED, AND CLOSED AS A DECISION RATHER THAN AS WORK DONE.** The reviewer marked it "DO
BEFORE SUBMITTING" and called it the highest value-per-effort action available; trimcrae ruled on

record above, because the second overrides the first without refuting it.
⚠ **That this costs the paper nothing is a property of how the paper is written, not an opinion.**

weakens any of them, the exon-2 passage starts leaning on a sequence nobody has — and then this
decision has to be revisited rather than inherited.

gate. Which paper goes out, and when, is trimcrae's and is not implied by the list being finished.
