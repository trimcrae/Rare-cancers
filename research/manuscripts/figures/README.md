# Manuscript figures

**The binding rule is `AGENTS.md` → "Making figures".** Hand-written SVG with manually computed
coordinates is **banned**: it has no text measurement, so labels overflow their boxes, and nothing
here rasterises it, so the result cannot be inspected before it is committed. Every figure is
regenerated from committed data by a committed script, every caption states what the figure does
**not** support, and axis units, error-bar meaning and n are always stated.

## What is here

- **`fig1`–`fig5` + `figure-provenance.json`** — the five figures of
  [`nr4a3-fusion-transcriptional-output.md`](../nr4a3-fusion-transcriptional-output.md), generated by
  [`nr4a3_fusion_targets_figures.py`](../../modalities/nr4a3_fusion_targets_figures.py) with
  **matplotlib**, emitted as 300 dpi PNG (for inspection and for the preprint) and vector PDF (for
  submission). Regenerate with:

  ```bash
  pip install matplotlib                                          # not preinstalled in this sandbox
  python3 research/modalities/nr4a3_fusion_targets_figures.py
  python3 research/modalities/nr4a3_fusion_targets_figures.py --check   # stdlib-only, draws nothing
  ```

  ⚠ **Nothing in CI redraws these — but staleness IS detected.** `figure-provenance.json` stamps a
  content hash of every artifact each figure was drawn from, and
  `tests/test_nr4a3_fusion_targets_figures.py::test_the_provenance_stamp_matches_the_committed_artifacts`
  compares that stamp against the artifacts on disk. That test is collected by
  `.github/workflows/tests.yml`, so **changing a number a figure draws and not regenerating it turns
  the build red.** The correct response is to re-run the generator and commit the figure in the same
  commit as the number — not to re-stamp.

  ⭐ **Look at the PNG before committing it.** Three lookup bugs in the first run each produced a
  finished-*looking* figure — an evidence-class chart with four empty bars, a matrix whose two array
  columns both read "not computed", and a missing motif p-value. None raised an error; all three were
  caught by eye. The generator now refuses to draw rather than repeat them, but the habit is the
  actual guard.

- **`portfolio-quadrant.png`** — the prioritized-portfolio grid of
  [`emc-treatment-roadmap.md`](../emc-treatment-roadmap.md), rendered with matplotlib via
  `portfolio_quadrant.py`. Keep the cell membership in the script in sync with the table.

- **`fusion-architecture.svg`** + `fusion_architecture_figure.py` — a schematic, not a plot.
